# Public package scope

This package contains 11 skills: seven original ClickUp core stages under the user-authorized MIT grant and four Matt Pocock adaptations with verified same-commit MIT notices. The optional Karpathy adaptation is excluded because its full upstream copyright/permission notice was not established. A separate local draft retains it for review.

The release uses new Git history. Source transcripts, customer data, raw exports, private workspace identifiers, credentials, connector configuration and the adjacent local review evidence are not included. All bundled examples use fictional identifiers and role labels.

Before the initial push, the exact staged files and committed blobs are checked for common sensitive patterns and unintended paths, in addition to metadata, links and temporary installer behavior. Only this package is sent to the user-authorized personal public repository. Pattern scans have limits; they are not an absolute secret-detection guarantee.

The README describes only the included skill set. Read-only task checks never authorize status changes or publication. No live ClickUp integration, background monitoring or Claude runtime-loading certification is claimed. See [validation evidence](validation-report.md), [license scope](license-scope.md) and [workflow examples](workflow-examples.md).
