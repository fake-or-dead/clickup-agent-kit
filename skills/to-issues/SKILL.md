# Draft local issues

Use a supplied plan, scope, source receipt and settled decisions. Group work into independently verifiable outcomes. Use thin end-to-end slices when appropriate. Preserve explicit backend/frontend or other layer-specific requests.

For each draft, state outcome, concrete behavior, inputs, outputs, complete relevant contracts, observable acceptance, dependencies, owner and open inputs with impact. Use the [card template](../techlead-clickup-handoff/references/compact-card-template.md) or [task template](../techlead-analyse-clickup/references/tasks-template.md) as requested.

Return the local draft set and sequence. No mandatory quiz, tracker setup, issue creation, labels, parent updates or repository changes. Separate publication requires the exact content, destination, operation and authorization through [publish](../techlead-clickup-publish/SKILL.md).
