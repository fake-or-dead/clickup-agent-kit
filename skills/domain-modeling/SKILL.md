# Clarify the domain

Read the relevant source wording and any existing glossary. Identify overloaded terms, entities, relationships, ownership and lifecycle rules that change the requested behavior.

Use concrete normal and edge-case scenarios to distinguish meanings. Compare source wording with available code or contracts and label conflicts. Do not invent a business decision when evidence is missing.

Record resolved terms and invariant examples in the agreed local artifact. Keep proposals separate from confirmed rules. Record a substantial hard-to-reverse decision only when that documentation is requested or useful to the scoped deliverable. Do not create repository glossaries or ADRs automatically during collection or rebrief.
