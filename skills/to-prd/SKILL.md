# Draft a local PRD

Use the current understanding, sources and settled decisions. Read the [PRD template](../techlead-analyse-clickup/references/prd-template.md). Produce only the requested local draft, with problem, solution, users, scope, acceptance, design/testing decisions and unresolved inputs.

Do not start a mandatory interview or tracker setup. Ask only when an unresolved input affects the dependent step. State assumptions and continue independent work. Do not publish, apply labels, modify a repository or declare readiness for development.

This kit adaptation changes the installed skill's automatic publishing behavior. It is a local drafting supplement. External writes go through [publish](../techlead-clickup-publish/SKILL.md) only with concrete content, target, operation and authorization.
